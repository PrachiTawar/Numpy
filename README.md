# 🟨 NumPy Practice Repository

This repository contains Python scripts and notebooks to practice and explore the basics of **NumPy**, a powerful library for numerical computing in Python.

---

## 📌 Purpose

The goal of this repository is to:

- Learn and practice core **NumPy functionalities**  
- Understand **arrays, matrices, and numerical operations**  
- Apply NumPy in small experiments and projects  

This repository is intended as a personal learning project to strengthen Python and numerical computing skills.

---

## 🛠️ Topics Covered

- Creating NumPy arrays (`np.array`, `np.zeros`, `np.ones`, `np.arange`, `np.linspace`)  
- Array indexing and slicing  
- Array operations (addition, multiplication, broadcasting)  
- Mathematical functions (`np.sum`, `np.mean`, `np.std`, `np.dot`)  
- Reshaping, stacking, and splitting arrays  
- Random number generation (`np.random`)  
- Linear algebra basics (`np.linalg`)
